# 摸魚王 · 線上房間遊戲（文字版 MVP）

## 本機卡牌改版

- 模式選單分成單人練習／多人遊玩，固定一屏操作。
- 抽牌 → 選行動與可選道具 → 確認出牌 → 個人結果。首回合抽 2 張道具，之後每回合補 1 張，手牌上限 3 張；沒有額度或牌堆用盡時不抽。多人逾時未抽會在選牌階段自動補發。
- 單人練習的抽牌、選牌與結算不倒數，由玩家主動繼續；多人維持原回合計時。
- **連續工作 3 回合會過勞猝死、成為幽靈**，免死金牌不能抵擋。連做 2 回合後會警告，改選休息、摸魚或協查可歸零。
- 結算顯示本人的行動、巡查位置、點數與心悸實際增減；最後一回合也先看結果，再進入終局。
- 原始封面、大廳、場景繪本保留，角色頭像與場景卡直接使用原圖。
- 本機啟動：`PORT=3001 npm start`。規則測試：`node --test tests/card-flow.test.cjs`。

房主開房 → 分享 4 碼代碼 → 大家加入 → 選/抽角色 → 自動跑回合。卡牌未定，先用文字（選地點、看結算）。

## 技術
- Node.js 20 + Express + Socket.IO，單一容器，房間狀態存記憶體（重啟即清空）。
- 前端：`public/index.html` 單頁，Socket.IO client 由伺服器自帶（不連外網）。

## 啟動（Docker）
```bash
cd 05_線上遊戲
docker compose up -d --build
# 瀏覽器開 http://<這台主機IP>:8088
```
停止 / 看日誌：
```bash
docker compose down
docker compose logs -f
```

## 本機直接跑（不用 Docker）
```bash
npm install
npm start          # http://localhost:3000
```

## 目前實作的規則（線上 v0.1 = 簡單版核心 + 溫和版）
- 3–6 人，1 老闆 + 員工（老鳥/菜鳥，公開）。
- 地點：辦公室(安全,不算摸魚) / 茶水間·影印間(+2分,心悸+1) / 廁所·頂樓(+3分,心悸+2)。
- 每回合：員工暗選去哪、老闆暗選查哪 → 自動同時結算。
- 被抓（溫和版）：這次摸魚不算 + 心悸+2（菜鳥+3）；不直接出局。老鳥有 1 張免死金牌自動擋第一次。
- 心悸滿 6 出局。有人待辦公室 → 其他人各 +1 心悸。
- 限制：員工不能連兩回合待同一摸魚區；老闆不能連查同一地方 3 次。
- 職級：菜鳥摸魚 +1、被抓更痛(+3)；老鳥摸魚 −1、耐命(免死1)。
- 勝負：下班(6或8回合)時，摸魚次數過半且最多者=摸魚王；沒人過半或員工全滅=老闆贏。
