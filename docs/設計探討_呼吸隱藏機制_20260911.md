# 設計探討：呼吸隱藏（0~60%）vs 明確觀察（thinking-coach 分析）2026-09-11

> 種子：「員工躲的時候有『呼吸隱藏』按鈕（0~60% 逃過被抓）；老闆有『明確觀察』按鈕（0~60% 抵銷）」。

## 結論（兩階段）
- **階段一（已實作上線）＝純演出版 D0**：揭曉動畫中，被巡區玩家的 chip 先「🫁 屏住呼吸…」顫抖 1.6 秒才判生死。呼吸感的價值 80% 在體感、20% 在數學——演出版拿走那 80% 且零風險（resolveRound 零改動、bot/斷線不受影響）。
- **階段二（backlog，真人試玩後想要「憋氣能真的翻盤」才上）＝ A′ 限縮機制版**，規格已定版（見下）。

## 為什麼不直接上機率版
1. 現有被抓判定是**確定性猜心**（巡到=必抓），擋箭牌鏈四層（藉口→報信→罩→免死）全是「資訊/準備/資源」決策、零隨機。機率層是全鏈唯一純隨機，DNA 相斥。
2. 若隱藏是免費/事前配點＝沉沒成本不黏揭曉→被抓從「被讀穿」退化成「檔位沒開夠」→猜心滑向數值對沖。
3. 雙方免費投滿＝淨 0＝無腦稅；付費對稱博弈需把成本校準到「永遠投滿被支配」。
4. 即時 QTE 版（按住憋氣）與 server 計時/bot 無手/斷線健壯性正面衝突，淘汰。

## 階段二 A′ 限縮版定版規格（要上時照此做）
- **只有菜鳥能憋氣**（老鳥已有免死金牌；菜鳥被抓 +3💓 最重、正缺保命線）——擋箭牌層數橫向分流不縱向堆疊。
- 檔位：不憋 0／淺憋 +1💓=30%／拚命憋 +2💓=60%（**無論老闆來不來都扣**＝防無腦刷；💓 越近門檻越貴＝天然凸成本自我節流。絕不可用 💰 付——富者無腦刷）。
- 老闆「緊盯」：0／−1經費=30%／−2經費=60%，**每回合限盯 1 個巡查區**。
- 淨逃脫＝隱藏−觀察（floor 0），**擲骰插在擋箭牌鏈最前**（成功=held，不消耗下游任何牌）：憋氣roll→藉口→報信→罩→免死→真被抓。
- bot：貪懶高分區 ~40% 淺憋；穩健只在很安全時 25% 淺憋；搖擺隨機難讀；bot 老闆照模式卡（記仇對上回得逞區緊盯、佛系不盯、經費<2 不盯）。
- 插入點：resolveRound `if(caught){` 之後；submitChoice 員工/老闆段加驗證；reveal `caught==='held'` 接「鬆一口氣」動畫。
