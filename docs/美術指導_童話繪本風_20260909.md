# 摸魚王 美術指導：童話繪本風（The Storybook Direction）2026-09-09

> 定調：**成人職場諷刺，偽裝成童話繪本**（adult workplace satire disguised as a children's fairy tale）。
> 適用：線上版（05_線上遊戲）UI 換皮 ＋ 10 張場景主視覺 AI 生圖。
> 生圖模型建議（沿用 2026-09-03 決策）：角色一致性選 Gemini Nano Banana；單張延續風格可用 GPT-4o 圖像；文字一律不交 AI（走 HTML/產卡模板）。

## UI 總原則
按鈕**不做現代 App 按鈕**，改做：
- 🪵 木牌
- 📜 羊皮紙
- 🔮 魔法印章

讓使用者第一眼就知道：「這是一個故事。」

## 視覺連續性（10 張是一本書，不是 10 個獨立設計）

```
                📖 摸魚王童話書
                       │
          ┌────────────┴────────────┐
          ↓                         ↓
       首頁封面                   世界觀
          │
          ↓
        Lobby
          │
          ↓
       遊戲桌
          │
      ┌───┴────┐
      ↓        ↓
   Scene     Choose
      └───┬────┘
          ↓
        Reveal
          │
      ┌───┴────┐
      ↓        ↓
    任務      角色
      └───┬────┘
          ↓
        結算
          │
          ↓
       📖 THE END
```

對應線上版狀態機：SCENE → ADMIN → CHOOSE → RESOLVE → REVEAL → 下一回合，視覺與流程一致。

## UI 美術規範（每張生圖都要帶，防止 30 張圖不像同一個遊戲）

**固定──線條**
```
delicate hand-drawn ink outlines
slightly imperfect organic linework
```
**固定──材質**
```
aged parchment
visible paper grain
subtle watercolor bleeding
hand-painted gouache texture
```
**固定──角色**
```
cute exaggerated proportions
expressive faces
slightly oversized heads
small hands and feet
```
**固定──環境**
```
old wooden furniture
warm office interior
magical everyday objects
cozy clutter
```
**固定──色彩**
```
warm muted storybook palette
cream parchment / warm brown / soft green / dusty blue / muted red / golden yellow
```
**禁止（負面提示，每張都帶）**
```
no photorealism, no 3D render, no glossy mobile game UI,
no anime, no cyberpunk, no futuristic office,
no realistic corporate photography, no text, no watermark
```

## 與既有風格的關係
- 實體卡既定風格＝遊戲王日式復古牛皮紙木框＋綠皮哥布林上班族（04_美術素材 README）。
- 本指導為**線上版**的整體包裝方向；牛皮紙/木框/復古水彩基因相通，哥布林角色可融入 storybook 角色設計（cute exaggerated proportions 相容）。
- 文字鐵則不變：**卡面/UI 文字一律不交 AI 生圖**，走 HTML 模板（產卡模板工具）。
