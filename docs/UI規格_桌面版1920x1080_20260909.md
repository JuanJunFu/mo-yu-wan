> （該檔管風格與生圖 prompt；本檔管版面座標、Layer、動畫、素材檔名）。
> 實作對象：`05_線上遊戲/`；素材放 `public/art/`，檔名照本檔。

## 0｜全域規格

**Canvas**：1920×1080。安全區 X 80–1840／Y 48–1032；主要內容 X 120–1800／Y 80–1000。

**全域 Layer**
```
L0 Background / L1 Environment·Illustration / L2 Decorative Objects
L3 Gameplay Board / L4 Character / L5 Cards / L6 Information Panel
L7 Interaction / L8 Modal·Reveal / L9 Notification / L10 Cursor·Hover·Highlight
```

## 01｜首頁 Home
目的：第一次進入 → 建立世界觀 → 開始遊戲。
- Header：X80 Y48 W1760 H72；Logo X100 Y60 W180 H50；右上＝遊戲規則/音效/設定。
- Hero：全幅 1920×1080 AI 主背景。
- Logo：另生成透明 PNG 1920×600；實際 UI 約 W600×H190。
- 主按鈕：W360 H92 R18；Center X=960，Y=720。下方＝建立房間/加入房間；再下＝📖 規則。
- 動畫：背景慢速漂浮粒子；角色呼吸/小幅晃動；Logo fade 0→100%＋scale .95→1；開始遊戲 hover=木牌輕微下壓、click=0.15s scale。
- 素材：`home_bg_1920x1080.webp`、`home_logo_transparent_1920x600.png`、`home_decor_01.webp`、`home_decor_02.webp`。

## 02｜Lobby
目的：「誰進來了？房間什麼狀態？」
- Header X80 Y40 W1760 H80：左 Logo／中 ROOM 代碼／右 ⚙設定 🚪離開。
- 玩家區：X300 Y200 W1320 H600；Player Card W240×H150；Boss Seat W280×H180。
- 玩家角色圖 240×320 透明 PNG。
- 動畫：加入=seat fade-in＋Y30→0；等待=椅子輕晃；開始=角色暗下→Boss chair 金光→transition。
- 素材：`lobby_bg_1920x1080.webp`、`lobby_boss_chair_600x400.png`、`character_player_generic_512x768.png`、`lobby_decor_01/02.png`。

## 03｜遊戲桌 Game Table（最重要主畫面）
- Header H86：左 Logo／中「第 03 回合＋SCENE」／右 ⏱ 倒數。
- 地圖：X180 Y180 W1560 H540；五區橫排 `[座位]→[影印]→[茶水]→[廁所]→[頂樓]`（對應相鄰關係），每區約 W270×H300。
- 角色 180×260；Boss 220×320。
- Bottom HUD：Y820 H200＝玩家資訊/任務/心悸/摸魚/手牌。

## 04｜選擇行動 Choose
核心：玩家只關心「我要去哪裡摸魚？」
- Zone Card W280×H210 ×5；Action Card W300×H120（認真/邊做邊摸/擺爛＝任務系統三動作）。
- 選取動畫：Zone hover=金色描邊＋內部魔法粒子；選中=scale1.05＋golden glow；Action=翻牌式；Submit=紙張蓋章動畫。
- 倒數 90×90；最後 10 秒數字震動；逾時套規格預設（員工回辦公室/老闆不巡/主管不協查）。
- 素材：`choose_zone_desk/copy/tea/bathroom/rooftop_512x512.png`、`choose_bg_1920x1080.webp`。

## 05｜Reveal（最強情緒畫面，不是資訊頁）
- Boss 320×460；被抓員工 280×400；數值浮現（+2/+1/+3心悸）**全部不用小字**。
- Timeline：0.0 黑幕→0.4 場景→0.8 Boss→1.1 指向→1.3 抓捕效果→1.6 玩家震動→2.0 數值跳出。
- 素材：`reveal_boss_768x1024.png`、`reveal_caught_employee_768x1024.png`、`reveal_escape_employee_768x1024.png`、`reveal_effect_catch_1024x1024.png`、`reveal_bg_1920x1080.webp`。

## 06｜任務 Task
左 40%＝任務卷軸（Panel X160 Y180 W650 H680）；右 60%＝進度/回合/獎勵/風險（Progress X900 Y250 W700 H100）。
- 三行動：認真 +2／邊做邊摸 +1／擺爛 +0（直接反映任務規則）。
- Deadline 用**沙漏**，不用一般 progress bar。
- 動畫：完成=卷軸自動展開＋金色印章＋紙屑；逾期=沙漏快速下降＋紅色警示光。
- 素材：`task_scroll_768x1024.png`、`task_completed_stamp_512x512.png`、`task_deadline_hourglass_512x768.png`、`task_bg_1920x1080.webp`。

## 07｜場景卡 Scene（＝翻頁）
- Card X620 Y120 W680 H840（4:5）：SCENE 標→AI 插畫→卡名→本回合效果。
- 動畫：從中央翻出 Y-300→120、rotateY -90→0、0.8s；翻牌時紙張摩擦音＋魔法粒子。

## 08｜角色卡 Character（收藏卡感）
- Card X640 Y100 W640×H880：角色圖→名（老鳥）→台詞「這種事情我見多了。」→分隔線→免死 1／罩學弟 READY。
- 角色圖 512×768 透明 PNG；卡框另生 `character_card_frame_1024x1536.png`（AI 只畫角色，未來換裝容易）。
- 素材：`character_senior/junior/boss/supervisor/ghost_512x768.png`。

## 09｜結算 Result（故事結尾）
- THE END → 👑 摸魚王 → 角色大型插畫（W600×H650）→ 摸魚/心悸/任務/排名 → 再玩一次 → 返回大廳。
- 字級：Winner 72–96px／Score 48px／Secondary 28px。
- 動畫：黑幕→THE END→Winner Character→金色粒子→數值逐一跳出→按鈕。
- 素材：`result_emp_winner_1024x1024.webp`、`result_boss_winner_1024x1024.webp`、`result_draw_1024x1024.webp`、`result_confetti_1024x1024.png`、`result_bg_1920x1080.webp`。
